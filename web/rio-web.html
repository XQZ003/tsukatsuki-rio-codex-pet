Codex 里的实际大小

Codex 默认把宠物画成约 113 像素宽，并做平滑缩放，所以细小的动作会被抹平；在 Codex 的宠物设置里把大小调到 192，像素才是一对一的。她是黑发黑衣，深色背景上靠头发里加多的高光来看出轮廓，不在人物外面画线。

说明
  • 实时母版：动作按连续时间播放，姿势之间有真实的中间帧，眨眼、视线和微微转头跟随鼠标是实时的；她转头、被拎起或落地时，长发会整束跟着摆动再停稳。
  • Codex 帧模式：只显示烘焙进宠物图集的那几帧，并按 Codex 的规则播放（悬停切到“悬停”行，拖动时横向移动 ≥4 像素切到“被拎着拖”行，状态变化从第 1 格重播，非待机动作 3 轮后回待机）。这就是装进 Codex 后的样子。
  • 两种模式用的是同一套关键姿势：母版在每个宿主帧的时间点上，正好等于那一帧。
  • 这一版（v050）：睫毛恢复到原来的粗细和深浅：往上看只抬中段，两端用一个浅一点的像素连上；眼皮放低时外眼角空出的位置用旁边头发本身的颜色补，不再变黑，也不留浅色点。
